## English

**🌐 Live site:** <https://maszlaig.github.io/PanettiPhotography/>

Portfolio & booking website for photographer **Anett Palicskó** (Panetti Photography, Nyírbátor) — maternity, portrait, wedding, family and child photography. A one-page **static** site: no server, opens in any browser, uploadable to any host. Fully **bilingual (HU/EN)**, mobile-first responsive, no build step and no framework.

**Highlights**
- **Elegant cream + gold identity** — Cormorant Garamond (serif) + Mulish typography.
- **Animated intro logo** — draws itself, then dissolves; respects `prefers-reduced-motion`.
- **Filterable gallery** — organised by category (maternity, portrait, wedding, family, child) with a lightbox.
- **`mailto:` contact form** — no backend required.
- **Bilingual + SEO** — HU/EN toggle and Open Graph cards.

**Tech:** vanilla HTML/CSS/JS · no framework, no build step.

**Structure:** `index.html` · `css/` · `js/` · `kepek/` (categorised images, logos, favicon) · `dokumentumok/` (design doc PDF, HU + EN).

**Deploy:** upload the folder to Netlify / Cloudflare Pages / GitHub Pages. Full details: the **design document PDF** in `dokumentumok/`.

## Magyar

**🌐 Élő oldal:** <https://maszlaig.github.io/PanettiPhotography/>

Palicskó Anett fotográfus (**Panetti Photography**, Nyírbátor) bemutatkozó és foglaló weboldala — kismama, portré, esküvő, családi és gyermek fotózás. Egyoldalas, **statikus** oldal: nincs szerver, bármelyik böngészőben megnyílik, bármelyik tárhelyre feltölthető. Teljesen **kétnyelvű (HU/EN)**, mobil-first reszponzív, build lépés és keretrendszer nélkül.

**Kiemelt funkciók**
- **Elegáns cream + arany arculat** — Cormorant Garamond (serif) + Mulish tipográfia.
- **Animált nyitó-logó** — kirajzolódik, majd átúszik; tiszteli a `prefers-reduced-motion` beállítást.
- **Szűrhető galéria** — kategóriánként rendezve (kismama, portré, esküvő, családi, gyermek), lightboxszal.
- **`mailto:` kapcsolati űrlap** — backend nélkül.
- **Kétnyelvűség + SEO** — HU/EN váltó és Open Graph kártyák.

**Technológia:** vanilla HTML/CSS/JS · keretrendszer és build lépés nélkül.

**Szerkezet:** `index.html` · `css/` · `js/` · `kepek/` (kategorizált képek, logók, favicon) · `dokumentumok/` (tervdokumentáció PDF, HU + EN).

**Közzététel:** töltsd fel a mappát Netlify / Cloudflare Pages / GitHub Pages tárhelyre. Teljes leírás: a **tervdokumentáció PDF** a `dokumentumok/` mappában.
